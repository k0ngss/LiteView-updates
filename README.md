# LiteView · 轻看 下载与更新

此公开仓库提供安装包、可选 PSD/PSB 插件、版本清单和更新说明。应用源码及其 Git 历史继续保存在独立私有仓库，不在这里发布。

[下载最新版](https://github.com/k0ngss/LiteView-updates/releases/latest) · [版本清单](https://raw.githubusercontent.com/k0ngss/LiteView-updates/main/update.json)

在发布页的 Assets 中下载 `LiteView-Setup-版本号.exe`。安装包包含可选 PSD/PSB 插件，安装时可勾选。另提供便携 ZIP、独立插件 ZIP 和 SHA-256 校验值。查看发布页和下载均无需登录 GitHub。

0.1.12 新增极简“插件”管理入口，显示安装状态、支持格式，支持选择 DLL 安装/替换及启用/停用；停用对下次打开 PSD/PSB 生效。

程序每日最多检查一次；发现更高版本后显示“有新版”，用户选择“前往下载”才打开公开发布页。程序不会自动下载安装包或自动安装。0.1.11 用户可手动点击“更新 → 检查更新”立即检查 0.1.12。

0.1.10 及更早版本未配置更新地址，需要先手动安装最新版一次。0.1.11 及以后的用户可以继续使用这份公开清单检查更新。
