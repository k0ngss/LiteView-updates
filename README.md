# LiteView 更新清单

此公开仓库只提供版本清单和更新说明。LiteView 源码及安装包仍保存在私有仓库。

清单地址：[update.json](https://raw.githubusercontent.com/k0ngss/LiteView-updates/main/update.json)。客户端匿名读取，不需要 GitHub 登录或 Token。

程序发现更高版本后显示“有新版”，用户选择“前往下载”才打开浏览器；不会自动下载或安装。当前下载页面需要登录有私有仓库访问权限的 GitHub 账号。

0.1.10 未配置地址，需手动安装 0.1.11 一次；0.1.11 及以后版本可以从此清单检查后续更新。
