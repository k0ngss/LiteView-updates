# LiteView · 轻看 下载与更新

此公开仓库提供安装包、可选 PSD/PSB 插件、版本清单和更新说明。应用源码及其 Git 历史继续保存在独立私有仓库，不在这里发布。

[下载最新版](https://github.com/k0ngss/LiteView-updates/releases/latest) · [版本清单](https://raw.githubusercontent.com/k0ngss/LiteView-updates/main/update.json)

在发布页的 Assets 中下载 `LiteView-Setup-版本号.exe`。安装包包含可选 PSD/PSB 插件，安装时可勾选。另提供便携 ZIP、独立插件 ZIP 和 SHA-256 校验值。查看发布页和下载均无需登录 GitHub。

0.1.13 新增程序内“下载并安装”：只有用户点击才下载，显示进度并允许取消；校验安装包大小和 SHA-256 后处理未保存的图片，再关闭程序启动正常安装向导。下载、校验或保存失败会保留当前编辑。

0.1.14 新增插件管理页的一键下载安装：用户点击后才下载 PSD/PSB 插件，校验大小、SHA-256 和接口兼容性后安装。页面显示版本、支持格式、启用状态和大小，并支持检查更新、启用/停用及移除。下载支持进度与取消，失败保留原插件和当前编辑。

0.1.15 更新应用图标：细浅青相框、照片折角、白色山形和暖色日出，统一程序、安装器和卸载器，并提供七种图标尺寸。

0.1.16 更新为透明背景的清新蓝绿图标，搭配浅青折角与杏黄日出，适配深浅背景。修复标题栏仍显示旧图标的问题，空窗口引导、程序和安装/卸载器使用统一图标。

程序每日最多自动检查一次；发现更高版本后显示“有新版”，自动检查不后台下载安装。用户可点击“更新 → 检查更新”立即检查新版。

0.1.11 / 0.1.12 用户会继续通过“前往下载”打开本公开发布页，手动安装最新版一次后，以后的新版就能使用程序内“下载并安装”。旧客户端兼容新版清单，无需登录即可收到提示并下载。

0.1.10 及更早版本未配置更新地址，需要先手动安装最新版一次。0.1.11 及以后的用户可以继续使用这份公开清单检查更新。
