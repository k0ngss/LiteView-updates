# LiteView · 轻看

Windows 10/11 x64 原生图片查看与基础编辑工具。此公开仓库提供安装包、便携包、PSD/PSB 插件、版本清单和更新说明。

[下载最新稳定版](https://github.com/k0ngss/LiteView-updates/releases/latest) · [查看版本清单](https://raw.githubusercontent.com/k0ngss/LiteView-updates/main/update.json)

在发布页的 Assets 下载 `LiteView-Setup-0.1.21.exe` 安装。也可下载便携 ZIP；PSD/PSB 插件支持在程序内点击下载并安装，或使用发布页提供的独立插件包。查看和下载均无需登录 GitHub。每个版本提供 `SHA256SUMS.txt` 校验文件。

0.1.21 优化图片启动：图片解码与界面初始化并行，快速图片直接显示；文件夹扫描和自然排序改为后台执行，编辑输入框按需创建，减少大图像素复制和透明度运算。较慢图片显示加载状态，打开失败保留可操作窗口和已有图片。

本版包含 0.1.20 的石墨灰与冰蓝界面更新：精简工具栏与更多菜单，编辑面板按调整、尺寸和标注分组，窗口尺寸跟随系统显示缩放；插件、更新、下载进度、确认和关于页面统一样式。保留裁剪、文字、涂鸦、马赛克、旋转、尺寸调整、亮度与对比度等功能。

程序每次启动后延迟 1.5 秒在后台检查更新，有新版本时显示提示圆点。自动检查只读取清单；用户点击“下载并安装”后才下载，验证完整大小和 SHA-256，处理未保存图片后打开安装向导。安装升级保留原目录、PSD 插件选择及启用状态。

0.1.11 / 0.1.12 用户可通过“前往下载”打开发布页，手动安装新版一次后使用程序内更新。0.1.10 及更早版本需手动安装新版。

源码及完整 Git 历史保存在独立私有仓库。此仓库的 main 仅包含公开说明和版本清单；发布附件不包含源码。
